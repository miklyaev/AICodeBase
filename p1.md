# цель:
Сделать рефакторинг backend и frontend
- Необходимо убрать возможность ввода API ключа любому пользователю. API ключ должен вводиться администратором сайта через меню "Настройка API".
С главной формы убрать раздел "Настройки API"
- логин и пароль админа вводится заранее в файл.env, необходимо добавить соответствующие константы
- после ввода админом API ключа, тот сохраняется на backend в файле .env
- взаимодействие с llm будет по OpenAI совместимому API
- в .env нужно добавить возможность ввода baseUrl, chatModel, а также embedding модели
- по-умолчанию baseUrl = https://polza.ai/api/v1, chatModel = openai/gpt-4.1, embeddingModel = perplexity/pplx-embed-v1-4b
- внеси соответствующие изменения в README.md, tz-ai-rag-code-agent.md
